# Aionis Dashboard v2 — Near-Final Quant Model-Evaluation Interface

**Status:** Demonstrative synthetic data only — shows analysis methods + interaction structure, not final conclusions.

## Overview

Dashboard v2 is a **near-final-product analysis interface** for judging five evaluation dimensions of the Aionis quant model:

1. **Fit Quality (拟合质量)** — Do out-of-sample scores predict cross-sectional returns?
2. **Volatility Structure (波动结构)** — Is the edge stable or clustered/lumpy?
3. **Curve Evolution (曲线演化)** — How does performance accumulate and drift over time?
4. **Pre/Post-Event Differences (事件前后差异)** — Do returns behave differently around real events?
5. **Uncertainty (不确定性)** — How tight is the inference, and is it publishable?

## ⚠️ Critical Notice: Demonstrative Data Only

**This dashboard currently runs on SYNTHETIC/DEMONSTRATIVE data only.**

- **Purpose:** Demonstrate the analysis methods and interaction structure.
- **NOT:** Final conclusions or research results.
- **Future:** Real data will come from confirmatory runs (Phase B/C/D/E1).

Every chart in this dashboard carries the caption:
> *"Preliminary data — demonstrates the method, not a final conclusion."*

```bash
uv run streamlit run dashboard/app_v2.py
```

## Architecture

### Files

- **`dashboard/demo_data.py`** — Pure, deterministic synthetic-data generators (seed fixed to 0)
- **`dashboard/charts_v2.py`** — Pure plotly `go.Figure` builders (no Streamlit calls)
- **`dashboard/app_v2.py`** — The Streamlit UI (composes demo_data + charts_v2)
- **`tests/test_dashboard_v2.py`** — Hermetic tests for determinism + chart builders

### Design Principles

1. **Determinism** — All generators use `seed=0`. Same input → identical output.
2. **Anti-leakage** — DEMONSTRATIVE/SYNTHETIC labels prominent. No real result/ledger data.
3. **Modularity** — Files <800 lines, functions <50 lines. Pure functions preferred.
4. **Graceful degradation** — Dashboard renders even when some artifacts are missing.

## Data Sources

### Demonstrative (Current)

All current data is synthetic, generated by `dashboard/demo_data.py`:

- **Monthly IC series** — Plausible S&P 500 cross-sectional rank-IC (mean≈0, std≈0.06)
- **OOS panel** — Per-ticker scores and forward returns for scatter/quantile charts
- **L-S returns** — Monthly long-short portfolio returns for equity curves
- **CAR paths** — Cumulative abnormal returns around events for event-study demo
- **Bootstrap samples** — For uncertainty and forest plot charts

### Real Data (Future)

When confirmatory runs accumulate, real data will come from:

- **`runs/results/<config_sig>/ic_*.parquet`** — Monthly rank-IC series per arm
- **`runs/results/<config_sig>/oos_*.parquet`** — Full OOS panel (Gap 1 from design doc)
- **`runs/results/<config_sig>/ls_returns.parquet`** — Monthly L-S returns (Gap 2)
- **`runs/ledger.jsonl`** — Run metadata and config signatures

## Chart Suite

### Dimension 1: Fit Quality

- **Cumulative IC line** — State vs baseline, dual line with CI band
- **KPI tile row** — Mean IC, NW t-stat, IC-IR, hit-rate
- **Score vs return scatter** — Cross-sectional relationship with Spearman ρ
- **Quantile spread bar** — Alphalens-style top-bottom spread

### Dimension 2: Volatility Structure

- **IC histogram** — Distribution shape with normal overlay
- **Rolling 12-m IC vol** — Stability-over-time view
- **Drawdown curve** — Underwater plot from running max

### Dimension 3: Curve Evolution

- **Cumulative IC + CI band** — Bootstrap CI ribbon
- **L-S equity curve** — Log-y option, state vs base vs placebo
- **Rolling IC/IC-IR** — Dual-axis drift/fade detector

### Dimension 4: Event Study

- **CAR path** — Cumulative abnormal return over t−20..t+40 window with CI ribbon
- **Event vs non-event overlay** — Comparison paths
- **Per-event-type summary bar** — 13D / earnings / macro side-by-side

### Dimension 5: Uncertainty

- **CI half-width bar** — Across phases vs the 0.015 publishability gate
- **Forest plot** — Differential mean + 95% CI per arm/control
- **Bootstrap distribution** — Histogram of bootstrap replicates
- **Publishability badge** — Color-coded by gate (green = publishable)

## Sidebar Controls

- **Phase** — [B | C | D | E1] → Maps to confirmatory:first config_sig
- **Arm** — [state/enhanced | base] (Phase E1: prop vs base_self)
- **Horizon** — [10 | 21 | 42] sessions → 21 = frozen confirmatory; others = EXPLORATORY
- **Event Type** — [13D | earnings | macro] (drives Event Study tab only)

## Design References

Methodology templates (reused as patterns, not code dependencies):

All charts implemented in **native plotly** (already a dep). No new runtime dependencies.

## Anti-Leakage Safeguards

1. **No real data** — Demo generators use only numpy/pandas with fixed seed
2. **No ledger writes** — Dashboard is read-only
3. **No network calls** — No external APIs or data fetches
4. **Explicit labels** — Every chart shows "Preliminary data" caption
5. **Publishability gate** — The ±0.015 CI-half-width gate is a recurring visual cue
