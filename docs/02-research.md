# Evidence base

> Index of the research documents that ground Aionis's design decisions.

- **frontier_positioning.md** — learned world models are infeasible at MVP scale;
  the +7-Sharpe cross-sectional leakage cautionary tale (ChaosAI); the methodology
  wheels to adopt (purgedcv, moving-block-bootstrap DM, Harvey-Liu haircut).
- **quant-selection-research.md** — data-source selection; survivorship treated as
  an irreducible scope limit, not a bias (same set on both arms).
- **market-driver-framework.md** — the market-driver theory behind the feature
  bundles.
- **data-intake-rubric.md** — the 7-gate intake every third-party dataset must
  clear: license / PIT / no-revision / snapshot / exploratory-only / selection /
  politeness.
- **data-license-allowlist.md** — permissive licenses only (MIT / Apache-2.0 /
  BSD / CC0 / CC-BY-4.0).

Research docs carry evidence markers: **[F]** Fact, **[I]** Inference,
**[H]** Hypothesis, **[D]** Decision.
