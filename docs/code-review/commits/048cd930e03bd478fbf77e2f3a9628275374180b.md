## 对照参考
ex-self 均值代数 `(group_mean*n - self)/(n-1)` 本身是标准 leave-one-out 技巧，但 `size`（含 NaN 计数）与 `count`（非 NaN 计数）的语义差是 pandas 官方文档明示的陷阱（[pandas GroupBy user guide](https://pandas.pydata.org/docs/user_guide/groupby.html)：count 只计非 NA，仅当组内无缺失时才等于 size；[RealPython](https://realpython.com/pandas-groupby/)）。13D 事件的 backward `merge_asof` 对齐与 [pandas 官方 asof-join 文档](https://pandas.pydata.org/docs/reference/api/pandas.merge_asof.html) 的 PIT 用法一致。出处域名：pandas.pydata.org、realpython.com。

## 问题清单
### P1-1 ex-self 均值在含 NaN trail 的 SIC 组里算错（size vs count 语义错配）
- 描述：`gmean = grp.transform("mean")`（跳过 NaN）但 `gn = grp.transform("size")`（含 NaN 计数），`peer_mom = (gmean*gn - self)/(gn-1)`——当组内任一 peer 的 trail 未定义（前 `window` 个 session 的预热期、新入股票、缺价）时分母与"组和"错位。uv.lock 在 Python≥3.11 下锁定 pandas 3.0.5（`DataFrame.stack()` 不再丢弃 NaN），该 bug 是**活跃**而非潜在的：评审复现 group {A=0.20, B=0.10, C=NaN} 算出 A=0.125，而精确 ex-self 应为 0.10。该特征喂给 N=3 confirmatory 差分，属静默特征腐蚀（确定性错误，非 PIT 泄漏，H6 无法捕获）。
- 位置：`src/aionis/features/peer_momentum.py:61-65`
- 影响范围：所有含预热期/缺价 peer 的 SIC 组的 `peer_mom` 值（Phase D confirmatory 特征之一）。
- 修复建议：`gn = grp.transform("count")`，并加 mixed-NaN 回归测试。
- 修复成本：低
- 状态：已在 05264c69b88a5d4abb2c02636a95049f279ed0af 修复（同日，内部评审 HIGH-1）
