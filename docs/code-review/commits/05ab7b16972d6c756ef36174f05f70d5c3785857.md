### P3-1 迁移路径上「首个 checkpoint 即整体替换」与超时叠加会短暂丢其它 issuer 历史

- 位置：`scripts/form4_fetch.py:107`（该 commit 版本 main() seed 行）
- 影响范围：仅一次性 schema 迁移窗口；正常增量/首运行路径不受影响
- 修复建议：迁移场景（OUT 存在但无 cursor）下，保留旧聚合行直到对应 issuer 的新数据落盘（例如 seed 仍读入旧聚合、按 issuer 前缀替换）
- 修复成本：中
- 状态：待人工复核（一次性迁移实际已发生完毕，风险已消解）
