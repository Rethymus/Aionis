## 对照参考
Atom 解析用 defusedxml 是 OWASP XXE Prevention Cheat Sheet（cheatsheetseries.owasp.org）对 Python 的推荐做法（标准库 xml.etree 对外部实体不安全）；Python 生态的 canonical Atom 库是 feedparser（BSD-2，github.com/feedparser/feedparser），本项目手写 + defusedxml 更轻且依赖面更小，合理。礼貌策略（≥2s host spacing + Retry-After 退避）与 tenacity/urllib3 的 Retry 语义（urllib3.readthedocs.io）一致。ticker 提取的「大写裸词」约定与 PRAW/WSB 数据研究文献的常见口径一致，但长度地板的取舍见 P2-1。
