## 问题清单
### P1-1 VIX PIT 前提错误：VIXCLS 在 ALFRED 无 vintage 历史
- 描述：本提交的 `fetch_vix_vintages`/`vix_as_of` 假设「ALFRED 给 as-of vintages，可无修订泄漏重建」——但 VIXCLS 实际是 unrevised 且不被 vintage 跟踪的序列（`realtime_start == realtime_end == 今天`，历史窗口请求 HTTP 400）。该前提在当日 Phase C 真实运行中被证伪。属于 PIT 事实性错误（领域红线），幸而为 exploratory 预备代码且未进入任何冻结结果。
- 位置：`src/aionis/ingest/vix.py:196-231`（fetch_vix_vintages / vix_as_of）
- 影响范围：Phase C 的 VIX 特征 PIT 口径；若未被发现会把「今天的快照」误当作历史 vintage
- 修复建议：改按 no-revision 契约（G3）以数据自身日期自证 PIT
- 修复成本：中
- 状态：已在 b8270049 修复（unrevised + self-dated vintages；文档 ddd77d06 同步更正）

### P2-1 ALFRED 分页循环无礼貌间隔
- 描述：`_download_vix_vintages` 的 `while True` 分页循环连续 `requests.get`，无 ≥2s 间隔；虽然 VIXCLS 单页即可取完（limit=100k），路径上仍是裸连发。
- 位置：`src/aionis/ingest/vix.py:163-182`
- 影响范围：FRED API 礼貌性（低概率触发限流）
- 修复建议：分页间 sleep ≥2s 或接入统一 http_policy
- 修复成本：低
- 状态：已在 b8270049/e8545d4 修复（vintage 路径重写 + AUD-05A http_policy host 级 ≥2s）

### P3-1 缓存写入非原子
- 描述：`to_parquet(pq)` / `cache_file.write_text(...)` 直接写目标路径，进程中断会留下半截文件，下次运行缓存命中即读到损坏文件抛异常，需手工清缓存。
- 位置：`src/aionis/ingest/vix.py:150`（`pd.DataFrame(...).to_parquet(pq)`）
- 影响范围：抓取中断后的恢复体验
- 修复建议：先写 `*.tmp` 再 `os.replace` 原子改名
- 修复成本：低
- 状态：未修复（仓库多模块沿用同一模式，属系统性小瑕疵）
