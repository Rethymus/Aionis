## 对照参考
`hac_mean` 的 Bartlett 权重 `1−lag/(L+1)` 与滞后规则 `4·(T/100)^(2/9)` 与 Newey-West (1994) 自动带宽一致（statsmodels `cov_type='HAC'` nw_automatic、MATLAB `hac` 同式；mathworks.com、statsmodels.org、nber.org）。embargo 语义（train 行 date ≤ t_w−5 sessions ⇒ 标签在重训时刻前已实现）符合 purge/embargo 文献标准做法（advances in financial ml 的 CPCV 语境）。
