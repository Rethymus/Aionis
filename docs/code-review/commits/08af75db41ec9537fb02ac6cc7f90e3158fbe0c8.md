## 问题清单
### P2-1 export_ic_monthly 不处理 NaN，tracked ic_monthly.json 含 11 处字面 NaN（非法 JSON）
- 描述：`rows = [{"month": str(idx), "us": float(r.us), ...}]` + `json.dumps(rows, indent=2)`——71 个月序列中 us/cn 各有缺失月，`float(NaN)` 序列化为字面 `NaN`，违反 RFC 8259；Python 端契约测试宽容通过（combined 列无 NaN），但严格解析器（JS JSON.parse/Jekyll）会拒绝该文件。该 commit 的 tracked `quarto-site/data/ic_monthly.json` 实测含 11 处 `NaN`。
- 位置：`scripts/export_quarto_data.py:121-123`（该 commit 版本）
- 影响范围：Quarto 站点渲染（CI Python 侧容忍）与任何严格 JSON 消费方。
- 修复建议：`None if pd.isna(v) else float(v)` + `json.dumps(..., allow_nan=False)`。
- 修复成本：低
- 状态：已在 c80838a21b915e54e85d6d2a5c899b6aee139b92 修复（脚本）；33035c3a21 重新导出对齐数据
