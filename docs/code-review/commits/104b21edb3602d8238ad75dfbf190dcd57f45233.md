## 对照参考
- **LightGBM 10k/query 硬限**：LightGBM lambdarank 有硬编码的每 query 10000 行上限（`LightGBMError: Number of rows ... exceeds upper limit of 10000 for a query`；github.com/lightgbm-org/LightGBM/issues/5053、lightgbm.readthedocs.io）。社区通行缓解正是「按截面拆分/采样 query」——月末采样（每 query ≈500 行）与官方语义一致且更贴合「月度横截面 rank-IC」估计算子。
- **折几何**：purgedcv 的 PurgedGroupKFold 以 [date, eval_date] 区间做 purge、以日历跨度做 embargo；把 `horizon=21/embargo=21`（session 语义）直接喂给**月末网格**面板会产生 ~21 个月的跨度（见 P2-1）——对照 purgedcv 文档语义可确认这是粒度换算缺失。
