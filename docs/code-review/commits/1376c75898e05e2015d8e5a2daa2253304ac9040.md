## 问题清单
### P3-1 月末定义是「每 ticker 各自的最后交易日」而非「共同月末交易日」
- 描述：`panel.groupby([ticker_col, "_ym"])[date_col].idxmax()` 取每只股票在该月**自己的**最后一根 bar。对流动性正常的股票等于共同月末 NYSE 交易日，但停牌/退市股的「月末」会早于共同月末——其 forward_return_h 窗口起点也随之提前，横截面内标签窗口不完全齐期。这是数据可得性下的合理 PIT 折衷，且退市股正是幸存者偏差敏感区，影响是「估计量轻微不纯」而非泄漏；未加披露注释。
- 位置：`src/aionis/eval/track_b_baseline.py:166-175`
- 影响范围：月末停牌/退市样本的标签窗口（少量）。
- 修复建议：在注释或 pre-reg 中披露该折衷，或统一用共同月末交易日并对缺 bar 者置 NaN。
- 修复成本：低
- 状态：未修复
