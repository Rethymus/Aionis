## 问题清单
### P2-1 无瞬时错误重试/重登录，单 code 失败丢弃整批结果
- 描述：`_query_one` 中 `if str(getattr(rs, "error_code", "0")) != "0": raise RuntimeError(...)`——不分瞬时（网络接收错误、会话过期）与永久（code 非法）错误，直接 raise；`fetch_ashare_prices` 循环内无 try/except 隔离，第 N 个 code 失败时前 N-1 个已耗费的结果（300 code × 2s pause ≈ 10 分钟）全部丢弃。baostock 社区实践明确建议"网络接收错误→有界重试→必要时重新 login()"。
- 位置：`src/aionis/ingest/ashare_price.py:81-86`（error_code 检查）、`:141-148`（批循环无隔离）
- 影响范围：Track C S0 真实拉取（949 ticker）的可靠性与重启成本。
- 修复建议：对瞬时 error_msg 模式做 ≤2 次指数退避重试 + 重新 login；或至少在批循环内 per-code try/except 收集失败清单后统一报告。已在后续 ba157f57e7aecf47cc3f00a865a56ccab20a515c 的拉取脚本层用 per-ticker try/except 隔离 + 人工覆盖核查缓解（"0 failures"），但适配器本身未改。
- 修复成本：中
- 状态：待人工复核（脚本层已缓解；适配器层未修复）

### P2-2 会话静默失效下"成功空帧"无异常检测
- 描述：baostock 连接静默失效时查询可返回 `error_code="0"` 但 0 行（社区实证的失效模式），本适配器对空结果静默返回空 DataFrame（`test_empty_result_returns_typed_empty_frame` 把这定义为正确行为），调用方若不核查覆盖即把缺口带进快照。
- 位置：`src/aionis/ingest/ashare_price.py:98-99`（`if not rows: return pd.DataFrame(columns=_COLUMNS)`）
- 影响范围：S0 快照数据完整性（2016+ 窗口若某 ticker 意外空返会静默缺列）。
- 修复建议：对"应有大日期范围却 0 行"的 code 记 warning 日志，或在 fetch 层加期望交易日历覆盖断言（后续 ba157f57 脚本以人工覆盖核查补上：20 个空 ticker 全为 pre-2016 成员）。
- 修复成本：低
- 状态：待人工复核（脚本层人工核查已做；适配器层告警未加）
