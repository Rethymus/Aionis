## 问题清单
### P2-1 裸词 ticker 匹配无英文常用词守卫，短代码 mention 严重失真
- 描述：`_TOKEN_RE = re.compile(r"\$([A-Za-z]+)|\b([A-Za-z]+)\b")` + `_count_ticker_mentions` 把正文中任意英文单词与 universe 大小写不敏感匹配。S&P 500 含大量 1-3 字母常用词代码（A、IT、GO、ALL、BIG…），帖子里的 "it"/"go"/"all" 都会累计为对应 ticker 的 mention 并捐出情绪票——`mentions`、`sentiment_mean`、`bull_ratio` 对这些代码近似等于全样本均值，特征被系统性污染。
- 位置：`src/aionis/ingest/reddit_sentiment.py:93`（`_TOKEN_RE`）与 `:249-270`（`_count_ticker_mentions`）
- 影响范围：retail-attention 前向序列（exploratory，G5 声明不进 confirmatory，故未触红线但伤信号质量）
- 修复建议：裸词匹配至少要求长度 ≥3/4 + 英文停用词黑名单，或仅统计 cashtag + 大写精确匹配
- 修复成本：低
- 状态：未修复（main 中 `_TOKEN_RE` 与裸词匹配原样保留；后续 0677acf5 的 RSS 路径复用同一函数）

### P3-1 PRAW 子版块间隔 1.5s 低于 ≥2s 红线

- 位置：`src/aionis/ingest/reddit_sentiment.py:78`、`:345`
- 影响范围：Reddit API 礼貌性（prawcore 100QPM 内建限流使实际风险低）
- 修复建议：提到 2.0s
- 修复成本：低
- 状态：未修复（main 仍为 1.5）
