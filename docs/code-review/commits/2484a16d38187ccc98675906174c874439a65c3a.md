### P3-1 Plotly CDN 脚本未加 SRI 完整性校验
- 描述：`<script src="https://cdn.plot.ly/plotly-2.27.0.min.js">` 无 `integrity`/`crossorigin` 属性。版本虽已钉死，但公网展示页引用第三方域脚本而不带 SRI，CDN 被篡改时任意 JS 可在该页执行（OWASP 对第三方托管脚本的基线要求）。测试甚至专门断言「除 plotly CDN 外无外部请求」，说明外联面被审过，只差 SRI 一步。
- 位置：`scripts/build_static_site.py`（`assemble_html_page` 中 `<script src="{PLOTLY_CDN}">`，约 L552）
- 影响范围：公开 Pages 站点的供应链完整性。
- 修复建议：加 `integrity="sha384-..." crossorigin="anonymous"`（版本已钉死，哈希稳定）或把 plotly.min.js 直接内联进产物（自包含，零外联）。
- 修复成本：低
- 状态：未修复

### P3-2 三张 CAR 图共用同一份种子数据、仅改标题
- 描述：`demo_data._car_path()` 每次调用都新建 `_rng()`（seed=0），因此 dim3 的「CAR path」、dim4 的「CAR 13D」与「CAR Earnings」是三条逐字节相同的路径配三个不同标题——访客会以为看到了不同事件类型的（相同）结果。同时 `observed = 0.008  # From demo_data generation` 硬编码复写了生成器的魔数，demo 改均值后会静默失同步。
- 位置：`scripts/build_static_site.py:91-118, 182-184`
- 影响范围：演示可信度；小维护风险。
- 修复建议：给 `_car_path` 加 seed 参数（0/1/2），构建时显式区分；observed 改为 `demo_data._bootstrap_distribution().mean()` 动态取。
- 修复成本：低
- 状态：未修复
