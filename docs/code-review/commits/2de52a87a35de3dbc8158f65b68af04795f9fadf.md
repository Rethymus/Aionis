- 位置：`dashboard/app.py:186-187`（ci_lo/ci_hi 取值）与 `dashboard/app.py:218`（n_null 计算，该 commit 版本行号）
- 影响范围：仅展示层 headline 计数（Phase B 本地未 backfill 工件场景）；不触研究管线。
- 修复建议：schema-1 时将 ci_lo/ci_hi 标记为 unknown 并从 n_null 分母中剔除或显示「n/a」，或统一 backfill 工件后删除部分回退逻辑。
