## 对照参考
- 与 scikit-learn `VarianceThreshold`（scikit-learn.org）对照：sklearn 按特征全局方差过滤（ddof=0），本模块按 (月份, 特征) 分组截面 std（ddof=1）——对"某因子整体有变异但个别月份截面恒定"的面板病灶更对症，且只报告不删除，符合项目"审计而非静默清洗"的立场；与 feature-engine 的 DropConstantFeatures/DropNearConstantFeatures 的常量/近常量二分法（feature-engine.trainindata.com）相比增加了 ALL_MISSING/FEW_VALID 覆盖面维度。

## 问题清单
### P3-1 非数值特征列在循环中抛未分类的 pandas TypeError
- 描述：`valid_values.std(ddof=1)` 对 object/字符串 dtype 列会抛 `TypeError: could not convert...`，绕过模块声称的 fail-closed ValueError 边界校验；诊断工具面对脏面板应报结构化 verdict 而非崩溃。
- 位置：`src/aionis/features/diagnostics.py:143-145`
- 影响范围：混入非数值列的真实面板（如 ticker 元数据列）会使整次诊断中断
- 修复建议：入口处对每列做 `pandas.api.types.is_numeric_dtype` 检查，非数值列直接裁决为一个新的 NON_NUMERIC 类别或 raise 带列名的 ValueError。
- 修复成本：低
- 状态：未修复（后续 ff5 挂载未见补此校验，待人工复核）

### P3-2 判定优先级未在 docstring 声明，FEW_VALID 会掩盖 NEAR_CONSTANT
- 描述：五类裁决按 ALL_MISSING→CONSTANT→FEW_VALID→NEAR_CONSTANT→VARIATION 短路；一个 valid_count=3 且 std≈1e-9 的 (date, feature) 只报 FEW_VALID，近常量信息丢失。docstring 列举了类别但未声明优先级。
- 位置：`src/aionis/features/diagnostics.py:130-186`
- 影响范围：仅诊断信息完整性
- 修复建议：docstring 声明优先级；或 reason 字符串附带次级标记。
- 修复成本：低
- 状态：未修复
