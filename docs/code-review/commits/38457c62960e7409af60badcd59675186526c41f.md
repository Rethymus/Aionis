## 问题清单
### P1-1 Dimension 1（alphalens IC 时序图 + 分位收益图）产出为两张字节级相同的空白 PNG
- 描述：`fig = plt.figure(figsize=(14, 6))` 后调用 `plotting.plot_ic_ts(ic)` 与 `plotting.plot_quantile_returns_bar(mean_ret)` 均未传 `ax=`；alphalens 内部自建新画布绘图，而 `_fig_to_base64(fig)` 保存的是先前创建的空 `fig`——两张图均为空白画布。证据：本 commit 提交的 `site/index.html` 中前两张嵌入图 base64 长度均为 6566 字符（≈4.9KB 空白图），且 `sort -u` 后仅 1 行（字节级相同）；其余真实图表为 35k–112k 字符。公开 Pages 站点因此展示了两个空白图位。
- 位置：`scripts/build_static_site.py:100-119`
- 影响范围：公开 dashboard Dimension 1 全部图表（2026-08-02 至 f6af91a 重建前的线上访客）。
- 修复建议：先取返回的 axes（`ax = plotting.plot_ic_ts(ic)`）再 `_fig_to_base64(ax.figure)`，或创建 fig/ax 后显式传 `ax=`；并给测试加「图像互异 + 最小字节」断言。
- 修复成本：低
- 状态：已在 f6af91a 修复（整站重写移除了 alphalens 图表生成）
