## 对照参考
pandas-datareader 官方文档（pandas-datareader.readthedocs.io/readers/famafrench.html）与源码（github.com/pydata/pandas-datareader）：famafrench 读取器**无内建缓存**，官方数据源为 Kenneth French 数据库（mba.tuck.dartmouth.edu）；社区共识是取一次后本地持久化（to_parquet）再复用。本 runner 两臂各自在线拉取同一日期范围的 FF5，与该实践相悖，也与本项目「所有抓取点 ≥2s 间隔」的礼貌红线不符。
