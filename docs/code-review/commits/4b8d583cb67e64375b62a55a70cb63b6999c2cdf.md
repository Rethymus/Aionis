## 对照参考
PSI 的标准做法（credit-risk scorecard 生态）是以期望样本（历史）分位数定 bin，把当前样本超出 bin 范围的值 clip 进首/末 bin，零占比用 epsilon 兜底。本实现 epsilon 兜底正确，但用 `np.histogram(sam, bins=edges)` 会直接丢弃超范围样本值再归一化，与 canonical 实现（mwburke/population-stability-index、R scorecard `perf_psi`、RunCell PSI calculator）不一致。参考：github.com/mwburke、search.r-project.org（scorecard）、numpy.org（np.histogram/np.digitize 越界语义）。

## 问题清单
### P2-1 PSI 丢弃超出历史 bin 范围的 recent 样本值，系统性低估漂移
- 描述：`sam_counts, _ = np.histogram(sam, bins=edges)` 中 `edges` 来自历史分位数；`np.histogram` 会把落在 `[edges[0], edges[-1]]` 之外的样本值排除在计数外，随后 `sam_pct = sam_counts / max(sam_counts.sum(), 1)` 又按实际计数归一化——即 recent 分布移出历史支撑的那部分质量被静默丢弃而非计入首/末 bin。恰恰在"显著漂移"（本 commit 实测 CN PSI 0.534 的场景）下该偏差最大，可能把 significant 低估为 moderate。
- 位置：`src/aionis/eval/model_drift.py:84-86`
- 影响范围：/model-health 页面的 PSI 与 regime 徽章（display-only，不影响研究结论，但这是该页面的主指标）。
- 修复建议：计数前 `sam = np.clip(sam, edges[0], edges[-1])`（或将外层边设为 ±inf），使越界质量归入首/末 bin；补一个均值整体平移出历史支撑的单测断言 PSI 更大。
- 修复成本：低
- 状态：未修复（`git log 4b8d583..main -- src/aionis/eval/model_drift.py` 无后续提交）
