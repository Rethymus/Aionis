## 对照参考
recharts 类目轴对 dataKey 不存在的字段取 undefined、不画线（recharts.org 文档 XAxis dataKey 行为），正是本次空图表的机制。前后端数据契约漂移的经典对策是 schema 校验双端共享或 codegen（如 JSON Schema + ajv，或 GraphQL codegen 思路）；本项目 Python 侧契约测试（test_web_terminal_data.py）只验 JSON 形状、不验 TSX 绑定字段，属单侧契约。
