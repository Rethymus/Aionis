## 对照参考
与 bt（MIT）官方 commission 模型对照（pmorissette.github.io/bt）：bt 在**每次 rebalance 触发的每笔交易**上调用 commission 函数，等价于"逐 rebalance、按真实交易量计费"——本修复版的 per-period `cost_t = bps × turnover_t` 与该惯例一致，且 union-reindex 对成员进出的计费方式正确处理了指数成分变化；no-drift（realized=0）简化在 bt/zipline 的实践中也是常见保守近似。反退化测试（stable→低换手、churn→高换手、成本线性）符合 arXiv 2603.20319 对实现风险成本的强调。来源域名：pmorissette.github.io、github.com/pmorissette/bt、arxiv.org。
