## 对照参考
OBF 边界 z_k = z_α/√I_k 与经典 Lan-DeMets OBF analog（gsDesign `sfLDOF`、rpact `asOF`、Jennison & Turnbull 2000 框架）一致：早期 look 临界值大、末期收敛到 z_α。等价判定用双侧 RCI ⊂ [−δ, δ]，在 μ=±δ 处 per-look I 类误差 = Φ(−z_k)=α_k，族误差由 OBF spending 控制（保守 ≤ α）。出处：keaven.github.io/gsd-tech-manual、rpact.org vignettes。数值抽查全部吻合。

## 问题清单
### P3-1 docstring「stops at the first look」与实现不符
- 描述：`sequential_equivalence_gate` 文档称 "Stops at the first look where RCI ⊂ ..."，实现却在声明 EQUIVALENT 后继续计算所有 look（注释称留审计痕迹）。verdict 语义仍正确（`stopping_look is None` 门闩保证首look定案），但读者可能误以为计算提前终止。
- 位置：`src/aionis/eval/sesoi_gate.py:283-292`
- 影响范围：仅文档/审读体验；统计结论不受影响。
- 修复建议：改 docstring 为 "verdict is fixed at the first EQUIVALENT look; remaining looks are computed for audit trail"。
- 修复成本：低
- 状态：未修复

### P3-2 `look_summary` 假定 IC 序列已按时间排序但未断言
- 描述：`ic_at_look = ic_series.iloc[:n_obs]` 按位置截断前 n_obs 条；若调用方传入未排序序列，look 截断将混入未来月份（等效前视）。当前唯一生产路径 `rank_ic_monthly` 返回 `sort_index()` 后的序列，尚安全。
- 位置：`src/aionis/eval/sesoi_gate.py:224`
- 影响范围：未来直接喂未排序 IC 序列的调用方。
- 修复建议：入口处 `ic_series = ic_series.sort_index()` 或断言 `index.is_monotonic_increasing`。
- 修复成本：低
- 状态：未修复

### P3-3 `sesoi` 未做正值校验
- 描述：`equivalence_verdict` 对 `sesoi<=0` 不报错——`sesoi=0` 时几乎必然 NOT_EQUIVALENT、负值则语义反转，均为静默错误。
- 位置：`src/aionis/eval/sesoi_gate.py:168`
- 影响范围：误配置调用方。
- 修复建议：加 `if sesoi <= 0: raise ValueError`。
- 修复成本：低
- 状态：未修复
