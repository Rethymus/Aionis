## 对照参考
pandas 官方 "Consequences of Duplicate Labels" 指南（pandas.pydata.org）确认：索引含重复标签时，唯一标签的标量查找会降维返回标量、重复标签返回 Series——正是本 bug 根因。官方推荐的一致返回类型写法是**列表索引器 `s.loc[[label]]`**（恒返回 Series），比本 commit 的 `isinstance(month_returns, pd.Series)` 事后检查更惯用；`groupby(level=0)` 亦可。参考：pandas.pydata.org/docs/dev/user_guide/duplicates.html、stackoverflow.com/questions/20383647。
