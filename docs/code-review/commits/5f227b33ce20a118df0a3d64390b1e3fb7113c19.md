## 对照参考
- arch 官方文档（arch.readthedocs.io / bashtage.github.io/arch）：`SPA`/`MCS` 构造器均接受 `seed` 与 `block_size`（内部 StationaryBootstrap），本 commit 以 `seed=0` 固定复现，与官方可复现性约定一致；官方另提供 `optimal_block_length` 做数据驱动 block 长度选择（本实现用 arch 默认 sqrt(n)，可接受）。
- Deflated Sharpe（Bailey & Lopez de Prado 2014）的闭式实现与 purgedcv 的 `deflated_sharpe_ratio_full` 公式一致（`_sr_variance`/`_expected_max_z` 镜像其内部），符合标准公式。

## 问题清单
### P1-1 DSR 以 n_trials=5 欠紧缩（单点族大小，非项目级诚实族）
- 描述：`eval_out = strategy_eval(ls, benchmark="arm_base", n_trials=len(ls))` 以本镜头内 5 个策略作为 DSR 校正族；而 docstring 自己写明 "The honest family size is the count of strategies actually evaluated **across the project**（Phase B + Phase C arms + controls）"，项目级族 ≈10+。单点 n_trials=5 会使 DSR p 值偏乐观——对一个以反泄漏/反多重检验为纲的项目，这是统计口径缺陷（exploratory 镜头缓解了严重度）。
- 位置：`scripts/strategy_eval_run.py:113`（`strategy_eval(ls, benchmark="arm_base", n_trials=len(ls))`）；`src/aionis/eval/strategy_returns.py:127`（`n_trials: int = 1` 单点设计）
- 影响范围：所有 DSR/dsr_p_value 输出与 `runs/ledger.jsonl` 中 strategy_return 记录的读者。
- 修复建议：按 trials 网格（1/2/5/20…）报告并取最大 trials 的保守 p 值（镜像 phase_c.N_TRIALS_GRID）。
- 修复成本：低
- 状态：已在 c6384e0fa99364342e645fc334d65d85dbb7ddc5 修复（`n_trials_grid=(1,2,5,20)` + `dsr_p_conservative`）

### P1-2 `deflated_sharpe` 未加守卫，退化策略会中断整个 strategy_eval
- 描述：`if np.isfinite(sharpe): dsr = deflated_sharpe(...)` 只挡 NaN，而 `deflated_sharpe` 在 `denom_sq<=0`（极端 skew×sharpe）或 `n_obs<2` 时直接 `raise ValueError`；SPA/MCS 各自有 try/except，唯独 DSR 没有——一条退化策略会炸掉全部 5 条的评估。
- 位置：`src/aionis/eval/strategy_returns.py:165-170`
- 影响范围：`strategy_eval` 全部调用方（strategy_eval_run.py 批量评估 5 面板）。
- 修复建议：与 SPA/MCS 对称地 try/except，退化为 NaN dsr 记录。
- 修复成本：低
- 状态：已在 c6384e0fa99364342e645fc334d65d85dbb7ddc5 修复
