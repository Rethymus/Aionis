## 问题清单
### P2-1 跨模块引用 universe 私有传输符号，传输策略无归属模块
- 描述：`from aionis.ingest.universe import _policy_get`（vix.py:42、event_text.py:32）与 `universe._HTTP_POLICY.spacing`（reddit_sentiment.py:54）。universe 是 S&P500 PIT 成分股模块，却成为全仓库 HTTP 传输策略的事实宿主；三个 fetcher 依赖另一个领域模块的下划线私有成员，重构 universe（如重命名 `_policy_get`、改 `_HTTP_POLICY` 构造）会静默破坏 vix/event_text/reddit。
- 位置：`src/aionis/ingest/vix.py:42`、`src/aionis/ingest/event_text.py:32`、`src/aionis/ingest/reddit_sentiment.py:54`
- 影响范围：所有走共享策略的 fetcher（vix/event_text/reddit_sentiment 及后续复用者）
- 修复建议：把 `_policy_get`/`_HTTP_POLICY` 上移到 `ingest/http_policy.py`（或新建 `ingest/transport.py`）并导出公开名，universe 与各 fetcher 统一从那里导入。
- 修复成本：低
- 状态：未修复（当前 main 仍为 `from aionis.ingest.universe import _policy_get`）
