## 对照参考
- pandas-datareader 官方 `famafrench` reader 将 ZIP 解析为按频率分节的 dict（Monthly/Annual 各有 PeriodIndex），不依赖固定行数（pandas-datareader.readthedocs.io）；社区教程（randlow.github.io）手工解析时也是用 `skiprows` + 到版权 footer/年度节边界为止的动态切割，而非 `nrows` 定值。本实现的 `nrows=755` 写死了"196307–202605"，属于脆性解析。
- 重试模式（单次重试 + 2s 延迟）与 urllib3.util.Retry / tenacity 的指数退避惯例方向一致，量级合规。

## 问题清单
### P2-1 兜底解析器硬编码 `nrows=755`，未来月份将被静默丢弃
- 描述：`df = pd.read_csv(f, skiprows=4, encoding="latin1", nrows=755)`，注释自述"755 rows from 196307 to 202605"。Kenneth-French 数据每月更新一次；2026-08 之后重跑该兜底路径时，第 756 行起的新月份会被 `nrows` 静默截断，FF5 回归样本悄悄滞后，无任何告警。当前 main 分支该行仍为 `nrows=755`。
- 位置：`src/aionis/eval/ff5_residual.py:313`
- 影响范围：`load_ff5` 走兜底路径的所有调用方（track_b mount 3 FF5 残差回归）；未来重跑会得到过期样本的 alpha/beta。
- 修复建议：不按行数截断——读取全部行后按首列 period 长度过滤（`len(str(period)) == 6` 保留月度 YYYYMM，自动排除年度节与版权 footer），或复用 pandas-datareader 的分节解析逻辑。
- 修复成本：低
- 状态：未修复

### P3-1 兜底请求未设置 User-Agent
- 描述：`urllib.request.urlopen(zip_url, timeout=30)` 使用 Python 默认 UA，部分学术站点（含 mba.tuck.dartmouth.edu）会拦截无标识请求；pandas-datareader 自身同样不设 UA，故非必然故障。
- 位置：`src/aionis/eval/ff5_residual.py:289`
- 影响范围：兜底下载成功率（次要）。
- 修复建议：构造 `urllib.request.Request(zip_url, headers={"User-Agent": "aionis-research/0.1 (contact: repo)"})`。
- 修复成本：低
- 状态：未修复
