## 对照参考
Tailwind 官方文档 Play CDN 页（tailwindcss.com/docs/installation/play-cdn）明确警告："The Play CDN is designed for development purposes only, and is not intended for production"——运行时 JIT 编译样式（首屏 FOUC、暗色主题闪白，见 stackoverflow.com/questions/79832150）且体积不可控；生产路径是 Tailwind CLI/PostCSS 构建期编译。本 commit 将 Play CDN 用于生产 GitHub Pages 站点，与其「reuse framework（正经用框架）」的自我定位相悖——用的是框架的玩具入口。参考站 参照站 的正确做法是构建期产物。
