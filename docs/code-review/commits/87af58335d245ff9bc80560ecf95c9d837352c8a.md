## 对照参考
Sharpe（mean/std·√12 月度年化）、Calmar、downside deviation 与 empyrical（github.com/quantopian/empyrical）对应函数语义一致，但 empyrical 的输入契约是收益序列；本 commit 以 IC 序列代理收益且 KPI 标签未披露该代理（见 P2-1）。CAR 的 mean±1.96·std/√n 跨事件 CI 是事件研究教科书公式。无新增依赖（明确拒绝 quantstats/ffn/empyrical）符合白名单纪律。
