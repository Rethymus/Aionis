## 问题清单
### P3-1 逐年拉取无隔离，annual.txt 清理不在异常路径
- 描述：`frames = [cot_year(y, ...) for y in YEARS]` 任一年下载失败（网络/上游变更）即整脚本异常终止，且 `Path("annual.txt").unlink(missing_ok=True)` 位于循环之后不会执行——cot_year 每次在 cwd 写 annual.txt，失败一次就留垃圾文件并丢失全部已拉取年份。
- 位置：`scripts/cot_fetch.py:48`、`scripts/cot_fetch.py:78`
- 影响范围：cot_fetch.py 运行健壮性（本地/CI）。
- 修复建议：逐年 try/except 跳过失败年并 finally 清理 annual.txt。
- 修复成本：低
- 状态：已在 77f6311a 修复（resilient per-year fetch + try/except）

### P3-2 MARKETS 含 2 个已知必 MISS 的条目

- 修复成本：低
