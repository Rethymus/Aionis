## 对照参考
涨跌停特征建模对照：A 股涨停价 = round(昨收 × (1±限幅), 0.01)，精确的 limit-distance 应按板别限幅（主板 10%、创业板/科创板 2020-08 起 20%、ST 5%）与昨收重构，而非 `|pct_change|/0.10`——后者在 ST 股上会系统性低估贴板程度（microsoft/qlib 的 cn collectors 与各类 A 股研究库均按板别区分；本项目 intake 文档亦知 ±20% 差异但特征实现未跟进）。月末截面采样与 `transform("max")` 的写法与 pandas 官方 groupby 惯例一致（pandas.pydata.org）。来源域名：pandas.pydata.org、github.com/microsoft/qlib、baostock.com。

- 位置：`scripts/build_cn_price_panel.py:37-56`（`_load_and_pivot_data` 后无成员 mask）、`:100-155`（`_build_features`/`_add_label_and_sample` 全程无 constituents 交集）
