## 对照参考
`_broadcast_surprise_z` 的"last-known-value + backward merge_asof"与 pandas 官方 `merge_asof` 文档的经典示例（quote→trade 最近邻匹配）同构：官方要求两侧按键预排序、`direction="backward"` 匹配 ≤key、`allow_exact_matches=False` 强制严格早于（pandas.pydata.org）。GDP 的 `by="prior_ref"` 分组 as-of 用法与官方 `by` 参数语义一致（先精确匹配分组键，再组内最近邻）。RD-13 截面恒定守卫（`features/diagnostics.py`）docstring 明示"macro-only interaction inputs"豁免——macro 6 在 region-month 组内恒定属预期设计（跨月变化供树结构做 regime 分裂），非违规。
