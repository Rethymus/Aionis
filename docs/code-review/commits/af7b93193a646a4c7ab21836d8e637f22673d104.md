## 对照参考
动量特征的通行定义是区间累计收益（pandas 官方惯用 `prices/prices.shift(w)-1` 或 `(1+r).prod()-1`；qlib/alphalens 的 momentum/ref 因子均按价格比值实现——qlib docs Alpha158 `KMID/REF`）。滚动求和版本仅在连续复利近似下成立，其误差项为 (S²−Σr²)/2，与窗口内波动率耦合。Amihud 复用与原实现一致（Amihud 2002）。

## 问题清单
### P2-1 momentum = 收益率滚动求和，而非累计收益；误差注释错误一个数量级
- 描述：`return returns.rolling(window=window, min_periods=window).sum()`，注释称「日收益 < 5% 时误差 < 0.1%」。实际误差 = prod(1+r)−1 − Σr = (S²−Σr²)/2：42 日窗、日波动 2% 时典型偏差 0.5–2 个百分点（趋势股系统性偏正、震荡股偏负），与横截面动量离散度同量级，且与个股波动率耦合——排序特征被波动率污染。docstring「动量等于累计收益率」名不符实；测试 `test_momentum_returns_cumulative_returns` 用求和自身作期望值且容差 0.01（1pp），无法区分两种实现。
- 位置：`src/aionis/features/price_features.py:82`
- 影响范围：Track B 全部 4 个 momentum 特征 + reversal（其负值），最终进入冻结 feature_cols 参与建模。
- 修复建议：改为精确累计 `prices/prices.shift(w) - 1`（或 `(1+returns).rolling(w).apply(np.prod, raw=True)-1`），并修正注释与测试期望。
- 修复成本：低
