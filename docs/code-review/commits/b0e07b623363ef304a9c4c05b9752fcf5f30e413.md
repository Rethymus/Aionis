## 对照参考
风险指标包装 empyrical（Apache-2.0，在许可白名单内；quantopian.github.io/empyrical 官方 API）：`sharpe_ratio(returns, risk_free, period, annualization)` 的 `risk_free` 官方语义为**每期**恒定无风险收益（新版源码明确 "constant daily risk-free return"），本模块 docstring 却写 "Annual risk-free rate"（见 P3-1）。历史分位数 VaR/CVaR 直算与业界标准做法一致。用 empyrical 而非 pyfolio（LGPL，项目禁用）是正确取舍。

## 问题清单
### P2-1 bearish_high 方向阈值 0.2 量纲错配，多数风险信号方向恒定
- 描述：`theme_signals.py` 对所有 `bearish_high` 信号统一 `threshold = 0.2  # conservative threshold for "low" volatility` 判方向。但 bearish_high 集合含 `leverage`/`debt_to_equity`（典型均值 1~5，恒 >0.2 → 恒 "bearish"）与 `amihud_illiquidity_21d`（典型值 ~1e-5，恒 <0.2 → 恒 "bullish"）——0.2 只对年化波动率量纲有意义，对 5 个 bearish 信号中的 3 个方向输出实际上是常数，"方向"展示失真。
- 位置：`src/aionis/eval/theme_signals.py:143-152`
- 影响范围：终端七主题面板中 leverage/debt_to_equity/amihud 三个信号的方向徽章（ef792bf 起消费）。
- 修复建议：按信号定义各自的中性阈值字典，或改为相对自身历史分位的 z>0/<0 判定；至少对不适配量纲的信号退回 'neutral'。
- 修复成本：中
- 状态：已在 ef792bfdd2e6896df7e3e396c371612b4b185085 修复（展示链路）——导出层用 latest-vs-trailing-6mo 趋势×极性重算 direction，模块的 0.2 阈值判定不再被展示消费；`summarize_theme` 函数本身的缺陷仍在，若被其他调用方直接使用会复现

### P2-2 strength 语义与规格不符：mean|z| 度量离散度而非信号强度
- 描述：`strength = mean(|z|)` 对近似正态的截面收敛到 ~0.8（√(2/π)），与信号水平无关——一个全市场高动量但截面离散度小的强 regime 会得到低 "strength"，而一个均值为零但厚尾的信号反而 strength 高。IA 提案（b1d195d）定义 "Strength: distance from neutral, normalized"（水平距中性），实现却是截面离散度。docstring "Normalized magnitude of the signal" 与实现同样不符。
- 位置：`src/aionis/eval/theme_signals.py:158-160`
- 影响范围：七主题面板的强度读数可能误导用户。
- 修复建议：明确选一种语义并改文档/实现之一：水平型 `|mean| / 全历史 std`，或离散型（改名为 dispersion）。
- 修复成本：低（改文档）至中（改指标）
- 状态：未修复

### P2-3 退化序列 NaN 无守卫，可产出非法 JSON
- 描述：`portfolio_risk.summarize` 在常数收益序列下 empyrical 的 sharpe/sortino 返回 NaN，`round(nan)` 仍为 NaN；`theme_signals` 中 `values.std()==0` 时 z 除零 → strength=NaN。`risk_summary_to_jsonable`/导出层 `json.dumps` 会输出 `NaN` 字面量（非 JSON 规范）。项目此前已在 ic_monthly.json 上修过同类问题（33035c3），此模块未加防护。
- 位置：`src/aionis/eval/portfolio_risk.py:104-133`、`src/aionis/eval/theme_signals.py:158`
- 影响范围：仅退化输入（常数序列/全同值截面）触发；真实数据概率低。
- 修复建议：输出前 `math.isnan → None/0.0` 归一，或在 summarize 入口检测零方差并返回 None 字段。
- 修复成本：低
- 状态：待人工复核（需查 ef792bf/2a1958d 导出链路是否已在下游消毒）

### P3-1 risk_free 量纲文档错误 + calmar 位置参数脆弱
- 描述：docstring 称 `risk_free: Annual risk-free rate`，但 empyrical `sharpe_ratio`/`sortino_ratio` 的该参数是**每期**收益率（默认 0 掩盖问题）；`empyrical.calmar_ratio(finite, risk_free, annualization=...)` 把 risk_free 传进了 `period` 形参（empyrical calmar 无 risk_free 参数），仅因 annualization 恒显式传入而未触发 KeyError——参数错位属侥幸不炸。
- 位置：`src/aionis/eval/portfolio_risk.py:117-130`
- 影响范围：任何非零 risk_free 调用会得到错误量纲的 Sharpe/Sortino。
- 修复建议：docstring 改为 per-period；调用改为关键字参数；calmar 调用去掉 risk_free。
- 修复成本：低
- 状态：未修复
