## 问题清单
### P3-1 `_load_run_meta` 对部分残缺 run 目录会抛未捕获 FileNotFoundError
- 描述：只判 `meta.json` 存在，随后直接 `R._read_json(d / "differential.json")` 等 5 个 JSON；若 run 目录只写了 meta.json（写入中断/手工损坏），多 run 视图（Overview/Uncertainty/Horizon）将抛 FileNotFoundError 使整页崩溃，且 `@st.cache_data` 会缓存异常前的半成品 dict 不成立（异常不缓存，但页面已挂）。
- 位置：`dashboard/app.py:76-88`（`_load_run_meta`，该 commit 版本行号 70-92 区间）
- 影响范围：仅展示层，残缺工件场景。
- 修复建议：逐文件 `if path.exists()` 判存，缺失键置 None/空 dict，或在 `meta_runs` 推导处 try/except 过滤。
- 修复成本：低
- 状态：未修复

### P3-2 跨模块访问私有函数 `R._read_json`
- 描述：`_load_run_meta` 直接调用 `aionis.reporting.results._read_json`（下划线私有），破坏模块边界——reporting 重构内部 JSON 读取时 dashboard 会静默断裂。
- 位置：`dashboard/app.py:82-87`
- 影响范围：可维护性/耦合。
- 修复建议：在 reporting 模块提供公开的 `load_run_meta(config_sig)`（JSON-only 变体），dashboard 只调公共 API。
- 修复成本：低
- 状态：未修复

- 描述：`_horizon_robustness_chart` 中 `d.get("mean_diff", float("nan"))` 没有像 `_headline_table`（上一 commit）那样回退 `mean_ic_diff_state_minus_base`，Phase B schema-1 工件在 h=21 处 y=NaN，B 折线在冻结 confirmatory 视界处静默断点；另外 `lo_err/hi_err` 在 CI 为 NaN 时记 0——若均值存在而 CI 缺失，图上会呈现「零误差棒」的伪精度。
