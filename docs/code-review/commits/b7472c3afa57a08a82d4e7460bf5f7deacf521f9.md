## 对照参考
requests/urllib3/tenacity 生态共识（scrapeops.io、oxylabs.com、oneuptime.com 十年沉淀的 retry 实践）：重试循环**绝不静默吞异常**——至少记录 URL/尝试次数/异常类型；只重试瞬态错误（408/429/5xx），4xx 快速失败。本 commit 的 `_policy_get` 已承载有界重试与退避（符合），但重试耗尽后的 `except Exception: pass` 违反「失败必须可观测」的共识；同仓库 616253e（stakes_13d fail-fast）与后续 97191ee 均印证此模式需修。

- 位置：`src/aionis/ingest/market.py:140`（`except Exception: pass`）
- 影响范围：volume 抓取的可观测性；turnover/amihud 特征覆盖率静默劣化。
