## 对照参考
「unrevised 序列以 no-revision 契约替代 vintage 重建」与 ALFRED 官方对 realtime 覆盖差异的说明一致（fredhelp.stlouisfed.org）；自日期合成（realtime_start == date）后做 backward as-of join 等价于对现值序列 reindex，merge_asof 语义见 pandas 官方文档（pandas.pydata.org）。测试 monkeypatch `pandas_datareader.get_data_fred` 保持 hermetic，与 pytest 官方 monkeypatch 用法一致（docs.pytest.org）。
