## 对照参考
Platt 缩放与 isotonic 对照 scikit-learn 官方 `CalibratedClassifierCV(method="sigmoid"|"isotonic")`（scikit-learn.org）一致；ECE 分箱实现与 Guo et al. 2017《On Calibration of Modern Neural Networks》标准定义一致。诚实地选择 Platt 为默认（零假设下收缩到 base rate 附近）与 sklearn 文档中 sigmoid 更不易过拟合的论述吻合。实现无 API 误用。

## 问题清单
### P2-1 `.date` 未调用，Python 内部字符串泄漏进 metrics.json
- 描述：`return str(pd.Timestamp(calibration["latest_date"]).date), ...`——`.date` 是属性不是调用，str() 得到 `"<bound method Timestamp.date of Timestamp('2026-08-03 00:00:00')>"`，已实际写入本 commit 的 `web/src/data/aionis/metrics.json:11`（latest_month 字段），部署后 hero 的"最新月份"显示 Python repr。`n_picks_total` 同时从 929（全截面数）静默变为 25（选股条数），字段语义漂移未披露。
- 位置：`scripts/export_terminal_data.py:150`（export_picks 返回行）；产物 `web/src/data/aionis/metrics.json:11`
- 影响范围：终端 Overview hero 的 latest_month 展示（线上脏数据持续约 5 天）。
- 修复建议：改 `.date()` 或 `.strftime("%Y-%m-%d")`；n_picks_total 语义变更同步注释/字段名。
- 修复成本：低
- 状态：已在 498bf09 修复（改用 strftime 并附注释说明此坑）

### P2-2 rank_change 跨区域编号偏移 + 索引刻度混用

- 修复成本：低
