### P1-1 harvey_liu_haircut 极端 p 值下灾难性消零 → +Infinity 且 survives=true（与自述结论相反）

- 位置：`src/aionis/eval/multiple_testing.py:484`（`z_bonf = float(stats.norm.ppf(1.0 - p_bonf))`）；触发于 `scripts/phase_b_run.py:117-119`（haircut_table）
- 影响范围：所有 §6 haircut 敏感性报告（Phase B 及复用该函数的后续 phase）；已污染 ledger #29 的 multiple_testing_haircut 字段
- 修复建议：改 `stats.norm.isf(p_bonf)`；并对 haircut_sharpe 施加 `min(sharpe, ...)` 上界断言（haircut 永不放大）
- 修复成本：低
