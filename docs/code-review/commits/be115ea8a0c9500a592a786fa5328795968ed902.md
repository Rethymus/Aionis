## 对照参考
trailing z-score 的 `shift(1)` 前置 + rolling 是 pandas 官方推荐的无前视窗口模式；`merge_asof(direction="backward", allow_exact_matches=False)` 与 pandas 官方 as-of join 语义一致；FRED observations 端点的 real-time 窗口对高频序列 vintage 查询有限制（100k 行/次上限 + vintage 日期约束，大窗口 daily 序列常见 400），per-year 切片是社区常见 workaround（fred.stlouisfed.org/docs/api/fred/series_observations.html、fredr 文档）。礼貌间隔 ≥2s 与项目对 FRED 的既有约定一致。
