## 对照参考
`merge_asof(direction="backward")` 做「发布即可见、其后保持 last-known」的广播与 pandas 官方 as-of join 语义一致（pandas.pydata.org/docs/reference/api/pandas.merge_asof）；列-only 特征拼接保持行布局不变以复用折索引，与 scikit-learn「同 X 行空间上叠特征」的约定同理（scikit-learn.org）。anomaly_audit 为自研纯检测，无直接开源对照（不适用）。
