## 问题清单
### P2-1 非对称模式部分传参被静默忽略（模式回退无告警）
- 描述：`asymmetric = us_feature_cols is not None and cn_feature_cols is not None`——若调用方只传了 `us_feature_cols` 而漏传 `cn_feature_cols`（或反之），函数**静默回退**到 shared 模式并忽略已传入的区域专属列，无 ValueError/警告。docstring 虽写了激活条件，但在 confirmatory 管线中这种 typo 会导致 estimand 从 41 特征静默退化为 10 shared 特征且不报错。
- 位置：`src/aionis/eval/track_c_joint.py:193`
- 影响范围：`fit_track_c_joint` 的全部调用方（`scripts/track_c_joint_run.py` 及后续 confirmatory runner）；错误配置将静默改变估计对象。
- 修复建议：当 `(us_feature_cols is None) != (cn_feature_cols is None)` 时 `raise ValueError("asymmetric mode requires BOTH us_feature_cols and cn_feature_cols")`，并在测试中固化。
- 修复成本：低
- 状态：未修复（后续仅 52a8d09 改过该文件的 concat sort 参数）
