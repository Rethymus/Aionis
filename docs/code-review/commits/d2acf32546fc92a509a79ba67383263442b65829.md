## 问题清单
### P1-1 累计 IC 随机游走带把 SE-of-mean 当月度 σ 用，带宽窄 ~√n 倍，视觉翻转 null 结论
- 描述：`_cum_ic_ci_band(cum_ic, monthly_se)` 的正确输入是**月度 IC 的 σ**；两处调用却写 `se = run["summary_state"].get("se_hac") or _ic_kpi(...)["std"]`——真实 run 恒有 se_hac（=σ/√n），fallback 的 std（=σ）永不生效。n=125 时带宽端点 = 1.96·σ ≈ 0.17，而正确带宽应为 1.96·σ·√125 ≈ 1.86：Phase B arm_base 累计 IC ≈ 1.81~1.9 会"冲出"错误带宽，图表据此宣称 detectable skill，与该臂 t_hac≈2.0（边缘）甚至非显著臂的真实判读相悖——对一个以诚实呈现 null 为纲的项目，这是旗舰图表的方向性错误。
- 位置：`dashboard/app.py:393-395`（view_fit_quality）、`dashboard/app.py:404-405`（view_evolution）
- 影响范围：Fit Quality 与 Curve Evolution 两个维度的核心图表读数。
- 修复建议：`se = _ic_kpi(ic)["std"]`（月度 σ）。
- 修复成本：低
- 状态：已在 2de52a87a35de3dbc8158f65b68af04795f9fadf 修复（HIGH-1，含 Phase B 验证 cum IC 1.813 ∈ ±2.017 带内）

### P2-1 headline 的 NULL 判据误用 |mean_diff| < 0.015
- 描述：`n_null = int((df["differential"].abs() < PUBLISHABILITY_GATE).sum())` 并渲染为 "N/M differentials within ±0.015 (NULL)"——本页自己的 caption 写明 "Verdict: NULL SUPPORTED when the differential CI brackets 0"。|diff|<0.015 既非 CI 跨 0 的必要也非充分条件（紧 CI 的 +0.014 可显著为正；跨 0 的 CI 其 |diff| 可任意小），该行会把显著正增量误计为 NULL。
- 位置：`dashboard/app.py:240`
- 影响范围：Overview 页汇总行；当前 B/C/D/E1 实测数据恰两判据一致，故今日未显错——属潜伏错判。
- 修复建议：`n_null = ((df["ci_lo"] <= 0) & (df["ci_hi"] >= 0)).sum()`。
- 修复成本：低
- 状态：已在 2de52a87a35de3dbc8158f65b68af04795f9fadf 修复（MEDIUM）
