## 对照参考
`_reliability_bins` 的等宽分箱 + ECE=Σ(n_b/N)|acc−conf| 与 sklearn `calibration_curve(strategy='uniform')` 语义一致；sklearn 不返回每 bin 计数（github.com/scikit-learn/scikit-learn/discussions/24123），故手写实现以同时产出 counts/ECE 是合理选择。参考 scikit-learn.org 官方文档与 kaggle.com 校准评估教程。
