## 问题清单
### P2-1 `skipna=True` 使部分日期静默退化为单层合成，违背"等权合成"规格
- 描述：`regime_composite` 用 `pd.DataFrame({name: s for ...})` 构造层矩阵时按**索引并集**对齐，`z.mean(axis=1, skipna=True)` 意味着某日只有 1 个层有值时仍输出该层单独的 z-score 作为 regime_state。macro 层与 global 层（DY 需 250 日窗口 + 126 日 z 预热）历史起点不同、US/CN 交易日历也不同，实际序列（commit 自述 2585/3021 valid）中存在宏观单层或全局单层主导的日期段——regime_state 的有效构成随数据可得性漂移，与 commit 信息宣称的"equal-weight of layers"及冻结 config 语义不符，且该行为无任何警告、无测试覆盖（测试全部使用相同索引的两层）。下游 conditional-IC 交互项会在不同日期比较不同构成的 regime 状态。
- 位置：`src/aionis/features/regime_composite.py:74`（`composite_raw = z.mean(axis=1, skipna=True)`）
- 影响范围：`regime_composite.parquet` 及所有下游使用 regime_state 的交互分析（conditional rank-IC）。
- 修复建议：要么 `z.mean(axis=1)` 配合 `z.notna().all(axis=1)` 掩码（全层在场才输出），要么显式 `min_count=len(layers)`，要么在 docstring/冻结 config 中明示"可得层等权"并加测试。
- 修复成本：低
- 状态：未修复（后续 f7c5789 仅扩展 builder 脚本至 3 层，库函数未动）

### P3-1 滚动 z-score 未防护 std=0
- 描述：`(series - mean) / std` 在窗口内序列恒定（std→0）时产生 inf/NaN，无守卫也无警告；早期 regime 层若出现常数段会静默污染合成。
- 位置：`src/aionis/features/regime_composite.py:41`
- 影响范围：极端数据形态下的合成层质量。
- 修复建议：`std.where(std > eps)` 或对 inf 做 clip + 警告。
- 修复成本：低
- 状态：未修复
