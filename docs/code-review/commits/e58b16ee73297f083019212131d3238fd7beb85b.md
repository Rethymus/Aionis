## 问题清单
### P2-1 枚举值用大写 NAME、event_type 大小写不符 gold schema
- 描述：规则 edge 写 `action: HOLD / actor_type: CENTRAL_BANK / temporal_class: MEDIUM` 等——冻结枚举的 value 是小写（hold/central_bank/medium），且 `event_type: 13D` 与 gold schema 的 `13d` Literal 不一致。该表的 HARD RULE 自称「Every edge field references values that exist in frozen enums」，按值匹配的加载校验会全部失败。独立 opus 审查列为 4 CRITICAL 之首。
- 位置：`evals/expected/zero_llm_rules_v1.yaml`（全部 10 条规则的 edge 块，如 L50-55）
- 影响范围：RD-08 实现若按表机械加载即失败/错配。
- 修复建议：全部改为小写 value（已在冻结版执行）。
- 修复成本：低
- 状态：已在 da764d0e 修复

### P2-2 缺 forward-guidance 抑制规则

- 位置：`evals/expected/zero_llm_rules_v1.yaml` FOMC 节（提案版无对应规则）
- 影响范围：zero-LLM 基线在 FOMC 样本上的精确率。
- 修复建议：增加 precedence 更高的 guidance-abstain 规则（已在冻结版以 `fomc_guidance_abstain_001`、precedence 110 落地）。
- 修复成本：低
- 状态：已在 da764d0e 修复
