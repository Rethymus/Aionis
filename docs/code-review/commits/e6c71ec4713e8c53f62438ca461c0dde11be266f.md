## 问题清单
### P3-1 测试只覆盖"无数据"路径，数据驱动路径未被断言
- 描述：测试经 `--out-dir tmp_path` 构建，而 `track_b_data.json`/`mount_metrics.json` 只存在于真实 `site/`，故构建时 `ic_data=None`、页面嵌入 `const icData=null;`。`test_data_driven_plotly_charts` 断言 `"icData" in generated_html` 对 null 同样通过——IC 序列真正嵌入 JSON 的路径（`icData.differential.ic_series` 结构、mount 指标表渲染）在 hermetic 套件中零覆盖。
- 位置：`tests/test_static_site.py:141-143`（test_data_driven_plotly_charts）
- 影响范围：build 脚本数据加载/序列化回归时测试不会失败。
- 修复建议：测试自建临时 out-dir 并写入最小 track_b_data.json/mount_metrics.json fixture，断言嵌入的 JSON 值出现在 HTML 中。
- 修复成本：低
- 状态：未修复
