## 对照参考
- Kolari & Pynnönen (2010, *RFS*)「Event Study Testing with Cross-sectional Correlation of Abnormal Returns」：事件日聚类时 Brown-Warner 型横截面检验统计量失准，需调整统计量（R `crseEventStudy` 实现之；econpapers.repec.org、cran.r-project.org）——正是本模块未处理的问题。
- Python `eventstudy`（lemairejean-baptiste，pypi.org/project/eventstudy）与 `EasyEventStudies`（github.com/Darenar/easy-event-study）：标准 AR/CAR 计算与本实现同构（等权/市场调整基准 + 横截面 SE）；eventstudytools.com/significance-tests 列 Patell-Z/BMP 等检验即针对此场景。本模块的市场调整模型 + 平衡面板丢弃策略与教科书一致，唯缺聚类稳健推断。

## 问题清单
### P2-1 across-event SE 忽略事件日聚类与窗口重叠，"95% CI" 反保守
- 描述：`se = cum.std(axis=0, ddof=1) / np.sqrt(n_events)` 假定事件间独立。earnings 事件天然按财报季聚集（多 ticker 同一 event_date、相邻事件窗口大量重叠），其 AR 共享同日截面冲击（benchmark 相减只除掉市场均值，剩余因子结构与异质冲击仍同源）→ SE 系统性低估，dashboard 上渲染的 `car_ci_lo/hi`（±1.96·SE）作为"95% CI"偏窄。设计文档自己引用了 Boehmer-Musumeci-Poulsen (1991) 标准化 AR 推断，实现未落地。
- 位置：`src/aionis/eval/event_study.py:155-157`
- 影响范围：dashboard v2 事件研究维度的显著性视觉呈现（ exploratory/methods-demo 定位缓解但不消除误导）。
- 修复建议：至少按 event_date 聚类做 cluster-robust SE（或 Kolari-Pynnönen 调整），或在图表上明示"独立性假设下的朴素 CI"。
- 修复成本：中
- 状态：未修复（该文件自本 commit 起至 main 无改动）

### P3-1 非交易日事件静默丢弃，无丢弃计数披露
- 描述：`if event_date not in position: continue` —— 13D/CPI 的披露日期落在非交易 session（节假日 filing、周末 BLS 发布边缘等）时事件直接消失；summary 只报幸存 n_events，丢弃量不可见。events_* 辅助函数也不做 next-session snap。
- 位置：`src/aionis/eval/event_study.py:110-112`
- 影响范围：事件覆盖率（尤其 13D 晚间/节假日 filing）不可审计；不同 event_type 的丢弃率差异会造成隐性选择。
- 修复建议：返回值加 `n_dropped_offsession`/`n_dropped_window`/`n_dropped_nan` 三个计数，或对 event_date 做下一 session 对齐并在 per_event 中记录原始日期。
- 修复成本：低
- 状态：未修复

### P3-2 earnings 事件用 10-K/10-Q filed 日替代实际公告日
- 描述：`events_earnings` 以 10-K/10-Q 的 filed 日为 earnings 事件日，而市场对 earnings 的反应锚定在 8-K/新闻稿公告日（常早于 10-Q 数天至数周）。docstring 未声明该代理性质，CAR[0] 的解读（公告日反应）会系统性偏移。
- 位置：`src/aionis/eval/event_study.py:199-215`
- 影响范围：Dimension 4 的 earnings CAR 曲线形状（公告后漂移窗口起点错位）。
- 修复建议：docstring 明示"filed-date 代理"，后续接入 8-K 公告日或 earnings_surprise 非零日。
- 修复成本：低
- 状态：未修复
