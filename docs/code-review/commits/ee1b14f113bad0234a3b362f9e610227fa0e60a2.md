- 位置：`src/aionis/ingest/news_sentiment_gdelt.py:61`（该 commit 版本）
- 影响范围：news_sentiment 主题整体（空面板），直到次日修复。
- 修复建议：新数据源接入必须附一次最小真实查询的冒烟验证（哪怕 1 个 chunk）；主题码对照官方 Category List。

### P1-3 无逐 chunk 持久化 —— 冷回填超时即全军覆没

- 位置：`src/aionis/ingest/news_sentiment_gdelt.py:230-258、291-305`（该 commit 版本）
- 影响范围：CI 冷启动路径；部分成功的 ~25 个 chunk 全部丢失。
- 修复建议：逐 chunk 聚合后即合并写缓存（季度对齐保证逐 chunk 聚合==整体聚合）。
- 修复成本：低
- 状态：已在 34eacb23 修复

### P1-4 增量游标永不回刷当月 —— 最新月份冻结在月头几天的部分样本
- 描述：`_next_fetch_start` 把下次抓取起点定为"缓存最后月份的下月 1 日"。当月（如 2026-08）在月初首次抓取后即被缓存，其月度聚合只含 1-3 天数据；此后每天运行 fetch_start=下月 1 日 > today → 判定 "cache_fresh" 跳过，当月值永不更新，月结束后也保持部分样本。主题的头条信号 `tone_latest` 因此系统性偏差。
- 位置：`src/aionis/ingest/news_sentiment_gdelt.py:296-306、353-356`（该 commit 版本；main 上仍原样）
- 影响范围：每个"最新月"的 tone/volume 展示值；sparkline 最近一点持续失真。
- 修复建议：`_next_fetch_start` 应回退到缓存最后月份的首日（merge_series 已是 new-wins 去重，天然支持重刷当月），或至少对最近 N 个月强制重取。
- 修复成本：低
- 状态：未修复（34eacb23 的 checkpoint 改造未触及该函数）
