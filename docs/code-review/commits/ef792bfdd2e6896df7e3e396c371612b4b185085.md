## 问题清单
### P2-1 strength 语义缺陷被继承且方法学串描述与实现不符
- 描述：导出直接沿用 `summarize_theme` 的 `strength = mean(|z|)`（截面离散度，正态截面恒 ≈0.8），真实数据 12 个信号 strength 全挤在 0.108~0.784，强度条缺乏区分度；且 methodology 串写 "Strength = |mean cross-sectional z-score|"——由于 z 已去均值，|mean(z)| 恒为 0，字符串描述的指标在数学上不存在，与代码实际计算的 mean|z| 不一致，披露失真。
- 位置：`scripts/export_terminal_data.py:602-610`（方法学串）、`src/aionis/eval/theme_signals.py:158-160`（继承的计算）
- 影响范围：/themes 面板强度条 + JSON 方法学披露的可信度。
- 修复建议：二选一——改方法学串为 "mean absolute cross-sectional z-score"，或按 IA 规格（b1d195d "distance from neutral"）改为水平型强度。
- 修复成本：低（改串）/中（改指标）
- 状态：未修复
