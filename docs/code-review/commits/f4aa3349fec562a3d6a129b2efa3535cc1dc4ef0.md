## 对照参考
`(sum - self) / (count - 1)` 的 ex-self 均值是 leave-one-out 聚合的标准向量化恒等式，与 pandas groupby transform 官方范式一致（pandas.pydata.org/docs/user_guide/groupby.html），同 Stack Overflow "group mean excluding current observation" 问题的公认解法（stackoverflow.com）；目标编码库 category_encoders 的 LOO 编码同用此代数。本实现额外处理了 pandas>=3.0 stack 保留 NaN 的陷阱，并配回归测试，成熟度高于常见开源片段。
