## 问题清单
### P3-1 `persist_snapshot` 未内嵌 I3 泄漏门，未来收集器可能漏调
- 描述：三个调用方都在 persist 前（各自）调用 `_common.assert_forward_clock(frame, _EVENT_TS_COL, snapshot_ts)`。新的 `persist_snapshot` 作为共享尾部未内置该防御后置条件，若未来新增收集器忘记在调用前自设泄漏门，无兜底。现三处调用均正确，仅是前瞻性健壮性缺口。
- 位置：`src/aionis/ingest/forward/_common.py:240-279`（persist_snapshot 函数体）
- 影响范围：仅影响未来新增的 forward 收集器（当前三个调用方行为正确）。
- 修复建议：在 persist_snapshot 增加 `event_ts_col: str` 可选参数，提供时自动执行 assert_forward_clock。
- 修复成本：低
- 状态：未修复

- 描述：`extra["n_rows"] = int(len(frame))` 无条件覆盖调用方传入的同名字段，无告警。当前无调用方传入，属防御性问题。
