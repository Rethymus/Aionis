### P3-2 空组边界可产出非规范 JSON（NaN）
- 描述：若 regime 全部 ≥ 中位数（如常数段），`lo` 为空，`float(hi.mean())`/`float(lo.mean())` 产出 NaN，`json.dumps` 默认 `allow_nan=True` 会写出 `NaN` 字面量——违反 JSON 规范，下游 jq/pandas 读取可能失败。
- 位置：`scripts/track_c_conditional_ic.py:96-99`（`"mean_ic_low_regime": float(lo.mean())` 等）
- 影响范围：极端数据形态下 `track_c_cn_conditional_ic.json` 不可被严格解析器消费。
- 修复建议：`json.dumps(..., allow_nan=False)` 前先 `None` 化 NaN，或对空组显式写 null。
- 修复成本：低
- 状态：未修复
