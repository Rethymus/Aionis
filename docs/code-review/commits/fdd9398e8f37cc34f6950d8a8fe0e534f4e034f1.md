## 对照参考
joblib `Parallel(backend="threading")` 适合释放 GIL 的底层（如 LightGBM C++ fit），但 LightGBM 并发 fit 的线程安全未由官方保证；下一个 commit 的实证（n_jobs=2 也静默崩溃 3 次）说明应按 joblib 官方建议先用小并发验证或直接 `backend="sequential"`。参考：joblib.readthedocs.io（Parallel/线程后端）、lightgbm.readthedocs.io（确定性章节建议固定 num_threads 以保证可复现）。
