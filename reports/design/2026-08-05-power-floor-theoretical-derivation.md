## 1. 闭式纯噪声界（Spearman 零分布）

**命题**：在"无预测力"零假设下，N 个资产的横截面 Spearman rank-IC 的标准差为

$$\sigma_{\text{null}}(\text{IC}) = \frac{1}{\sqrt{N-1}} \quad (N \ge 2).$$

**依据**：两独立排名的 Spearman 秩相关 ρ 的方差为 1/(N−1)（标准结果；精确，非渐近）。
这是**可达的最低 σ(IC)**——任何真实模型（哪怕纯噪声分数）的 IC 序列边际 σ 不应低于此界
（除非序列有强正自相关把边际 σ 拉低，但那会抬高 SE 而非 σ）。

**数值**：
| N_cross | σ_null |
|---:|---:|
| 100 | 0.1005 |
| 300 | 0.0578 |
| 462（Track B 中位） | 0.0466 |
| 500（S&P 500） | 0.0448 |
| 929（Track C CN 中位） | 0.0328 |
| 1386（Track C combined 中位） | 0.0269 |

## 3. 机制性结论（这是真正的理论贡献）

**power floor 不是纯数学必然，而是由 ML 噪声超额驱动**：

- 在**纯噪声界** σ_null≈0.047（N=462）下，look-3 (z=1.960) 的 n_min = (1.96×0.047/0.010)² ≈ **83 月** < 120 月
  → **纯噪声策略本可在 look-3 达等价**（边际有功率）。
- 在**实测中位** σ_obs≈0.109 下，look-3 n_min = (1.96×0.109/0.010)² ≈ **456 月** → **不可行**。
- **差额（83 → 456 月）完全由 2-4.4× 的 ML 噪声超额解释**。

**因此 honest 的 power-floor 表述**：

> 月频横截面 rank-IC 等价检验在 ±0.010 撞 power floor，**不是因为纯抽样噪声（1/√(N−1) 界在 look-3 本可
> 达），而是因为真实 ML rank-IC 的 σ 一致地比纯噪声界高 2-4.4×**（21 个 Aionis 系列 + 文献一致区间）。
> 该超额反映 ① ML 拟合噪声（模型在训练噪声上学到的"模式"在测试集产生时变 IC），② 横截面收益离散的
> 逐月异方差，③ 21-session 前瞻收益的相邻月重叠。**这是 ML-based 等价检验的结构性性质，非数据 artifact。**

这比"σ≈0.10 floor"**更精确**（给出界 + 超额分解）且**更诚实**（承认纯噪声界本可让 look-3 达等价；
不可达性来自 ML 噪声超额，而该超额是稳健的跨配置事实）。

## 4. 超额的来源（机制分解）

1. **ML 拟合噪声**：即使冻结特征无真实预测力，LightGBM 仍在训练噪声上拟合，使测试集 IC 时变（月间波动）。
   这是 σ_obs > σ_null 的主因——纯随机分数不会有时变结构。
2. **横截面异方差**：收益离散逐月变化（高波动月 IC 噪声更大）→ σ(IC) 序列波动放大。
3. **重叠前瞻收益**：相邻月 IC 共享 ~20/21 sessions 的 forward return → 诱导 IC 序列自相关。
   注：重叠主要影响 SE(mean)（通过 long-run variance），对边际 σ(IC) 的影响次之——但它放大了
   "拟合噪声的时变"在序列上的持续性。
4. **lambdarank 得分**：排序目标的 cross-sectional spread 逐月变化，间接影响 IC 的尺度。

**可检验推论**（若业主要后续验证）：在**合成纯噪声**（score = 随机，独立于 forward return）上跑同等折叠，
应得到 σ(IC) ≈ σ_null（验证界）；Aionis 的超额应消失——确认超额来自模型/数据结构，非估计量本身。

## 5. 对论文的影响（refined power-floor claim）

**原表述**（power-floor note v0.1）："σ≈0.10 使 ±0.010 等价不可达（look-3 需 36 年）。"

**升级表述**（本 note）：
> 月频 rank-IC 等价检验的 power floor 由两层构成：① **纯抽样下界** σ_null = 1/√(N−1) ≈ 0.03–0.05
> （闭式，N 为横截面大小）——该界本可让 look-3 (n=120) 边际有功率（n_min≈83）；② **ML 噪声超额**，
> 实测 σ(IC) 一致为 σ_null 的 2-4.4×（21 系列，min 2.03×），把 n_min 推到 ~456 月（38 年）。
> 超额稳健跨配置且与文献一致区间吻合；故 floor 是 ML-based 等价检验的结构性性质。

**更强但更诚实**：它不再依赖"σ≈0.10 是规律"的断言，而是分解为**可检验的界 + 实测超额**——审稿人可独立
验证纯噪声界（闭式）+ 在自己的 ML IC 系列上测超额比。
