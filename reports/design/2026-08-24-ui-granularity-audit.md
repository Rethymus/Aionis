# UI 颗粒度对齐审计 — 部署端（小隐寺皮肤）vs 本仓 UI（2026-08-24 深夜浏览器一手审计）

> 背景：业主判定"当前 UI 过于简陋，未真正对齐颗粒度"。审计实证：**data.xiaoyinsi.com 是本仓库的部署端**（其 /institutions 载有本仓的 40 位明星策展+中文别名+七分类按钮；侧栏"语境/效度/可证伪主张/守卫"= 本仓 IA；⌘K 面板同款）——**同数据、两套皮肤**。本任务 = 把本仓 UI 升到部署端皮肤的颗粒度。全部发现来自浏览器实测（非转述）。

## 一、全局设计 token 差距（部署端 → 本仓现状）

| 维度 | 部署端（对齐目标） | 本仓现状 | 动作 |
|---|---|---|---|
| 背景 | 纯黑 `rgb(0,0,0)` | zinc-950 系（半透明嵌套） | dark token → #000 |
| 字体 | `GeistSans` + fallback | Noto Sans SC | Geist 主 + Noto CJK 回退 |
| 容器 | `mx-auto max-w-[1320px] px-5 py-8 md:px-6` | 无统一 max-width | (dashboard) 内容层统一容器 |
| 正文密度 | /news 103KB /institutions 127KB 文本 | 明显稀疏 | 页内行密度提升（见三） |

## 二、导航与壳层差距

1. **双行侧栏项**（部署端全量 18 项，标题+说明两行）：
   概览 / 新闻·快讯 / Reddit·散户社区提及与热度榜 / TACO·川普霍尔木兹让步 / 机构目录·全部机构 / 机构持仓·真实持仓 / 新股·定价上市申报 / 内部人·高管与董事交易 / 重大事件·并购高管退市 / 举牌·主动被动披露 / 季报 10-Q / 年报 10-K / 公司目录·高管档案 / 明星投资人 / 政客交易 / API —— 本仓侧栏为单词单行。
2. **顶栏四件套**：`搜索 / 跳转⌘K`、**涨跌颜色约定切换（红涨绿跌/绿涨红跌）**、语言切换、主题切换 —— 本仓缺颜色约定切换。
3. 首页 = **数据驾驶舱**（hero 标语"看清美股背后的聪明钱" + 新闻快讯区 + 散户情绪榜区 + 政客交易区 + 探索全部数据模块区，25 卡）—— 本仓首页是"效度论证链"叙事页（保留叙事但**顶部加数据驾驶舱**或并列）。

## 三、页面级颗粒度差距（浏览器逐页实测）

| 页 | 部署端版式（对齐目标） | 本仓现状缺口 |
|---|---|---|
| /institutions | 横向分类按钮组带计数：`全部 (40) 价值 (9) 成长 (8) 激进股东 (6) 宏观 (5) 量化 (6) 华人背景 (4) 其他 (2)`；机构行 = 英文名+中文别名+分类徽章+申报日 | 已有 chips+卡但行密度与双名排版细度不足 |
| /congress | **三组 pill 栈**（党派：全部党/民主/共和；院：全部院/众议院/参议院；买卖：买入/卖出）+ **热门 ticker 芯片行**（MSFT GOOGL NVDA AAPL BRK.B HD META AMZN GS CAT）+ 顶部"共 N"计数 | 单组党派筛选；无院/买卖组；无 ticker 芯片行 |
| /news | 行内 **中文/英文** 语言分段切换 + "共 N"计数 + 高密度快讯列表 | 无语言切换 |
| /stock/MSFT | 顶部**芯片导航条**（持仓机构/政客/内部人/高管/基金 锚点跳转）+ KPI（评分/买入/卖出/市值） | 各模块纵向堆叠无锚点导航条 |
| /stakes | 持股比例徽章 + 状态徽章（已有对齐）；密度更高 | 基本对齐，密度待提 |
| 通用 | "共 N 条"计数前置；分页/加载更多统一形态 | LoadMoreFooter 已有，计数口径页头化不足 |

## 四、执行计划

- **基座（主线先行，全部页面继承）**：#000 背景 token、Geist+Noto 字体栈、(dashboard) 1320px 容器、侧栏双行项（nav.sub.* i18n zh/en 各 18 键）、顶栏涨跌颜色约定切换（CSS 变量 + localStorage，红涨绿跌为默认中文习惯）。
- **页面组代理（02:45 配额重置后并行四路）**：
  - **U1 组**：/congress（三组 pill 栈 + ticker 芯片行 + 共 N 前置）+ /news（中英分段 + 共 N）+ 通用页头计数窗推广。
  - **U2 组**：/stock/[ticker]（锚点芯片导航条 + KPI 行重排）+ /companies + /filers 行密度。
  - **U3 组**：/institutions + /manager/[cik]（双名排版 + 分类横钮精化 + 行密度）+ /executives。
  - **U4 组**：首页数据驾驶舱（新闻快讯/情绪榜/政客三区 + 探索模块网格，保留效度链于下）+ /events /taco /market 页头统一。
- 每路铁律：只改视觉/交互层不动数据管线；zh/en i18n 同步；tsc/eslint 绿；禁 next build（集成时主线统一）；每页改完 SSR grep 验证关键元素。
