# TASK-DISP-DES — 明星投资人诚实策展门槛规格（纯设计，零代码）

**Lane**: display / design-only。**优先级**: P1。
**工作目录**: 主仓 `F:\ZCodeData\Aionis`（只创建一个新文件，禁改其他任何文件）。
**授权**: 业主常设多 agent 指令。

## 0. 背景

差距地图（post-parity roadmap §1）记录：明星投资人面板 = 40 位诚实策展 vs 参照站宣称 43，
差 3 位的合法补齐路径 = "仅当有真实活跃管理人通过诚实策展门槛"。并行存在一个证据考察 agent
（产出 `reports/design/2026-08-26-stars-candidates-evidence.md/.json`，EDGAR 实证）。
你的任务是把这个"诚实策展门槛"从口头原则变成**可执行的书面规格**，使集成裁决有据可依。

## 1. 输入（先读再写）

- 现役 40 人 + 5 个停报剔除档案（git show 4405724 或当前导出注释/配置——以实际代码为准）：
  提炼既有隐含标准（申报连续性/公众身份/可归类别/中文名可得性曾被如何执行）。
- `form13f.json` 的字段形状（zh_name/category 在哪一层）与 `export_form13f_stars`
  的派生逻辑。
- 七分类的真实定义（value/growth/activist/quant/macro/china/other 的既有边界例子）。

## 2. 规格 = `reports/design/2026-08-26-stars-curation-bar.md` 必须回答

1. **准入判据（admission bar）**：逐条可判定规则——申报活跃度阈值（近 N 季无断报）、
   规模或知名度下限的代理指标、七分类可归类且不生造类、中文名有可靠出处
   （官方页面/权威财经媒体惯例译名；绝不机器直译生造）。
2. **排除判据（revocation/exclusion）**：停报断档多久出局（复用 5 剔除先例的实际口径）、
   与现有在册者同一实体不同壳的重复防护（CIK/名称双查）。
3. **证据要求（evidence schema）**：与并行证据报告的 JSON 字段一一对应；
   集成时的核对清单（哪几条必须 PASS 才准入；BORDERLINE 的处置 = 默认不进，宁缺毋滥）。
4. **裁决程序**：谁拍板（业主 GO / 主线按本规格代裁的适用条件——建议明确写出：
   全项 PASS 可由主线直接采纳并在 state 记录；任一 BORDERLINE 留业主）。
5. **落地改动清单**：一旦有人准入，需要动哪些文件（策展配置点/导出/契约测试锚值/首页卡自动跟随）
   ——精确到路径，供下一轮构建任务书引用。
6. **反目标重申**：绝不凑数到 43；数字目标不是目标，诚实是目标。

## 3. 边界

零代码改动；只创建上述一个 md 文件；零网络请求（材料全部在本仓 + 并行报告）；
若并行证据报告尚未落盘，按字段表独立成文，冲突留集成时调和并在文末注明。

## 4. 报告格式

(a) 文件路径；(b) 从 40+5 档案提炼出的隐含标准清单；(c) 准入/排除判据一句话摘要；
(d) 与证据报告 JSON 字段的对齐情况。
